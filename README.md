### 🏦 AI Investment Research Agent
**An autonomous, multi-agent hedge fund analyst — powered by LangGraph & Groq**

<a href="https://ai-investment-research-agent-mh1h.vercel.app/"><img src="https://img.shields.io/badge/🔴_LIVE_DEMO-22c55e?style=for-the-badge"/></a>
<a href="https://github.com/Sathvik33/AI-Investment-Research-Agent"><img src="https://img.shields.io/badge/View_Repo-6366f1?style=for-the-badge&logo=github&logoColor=white"/></a>

</div>

> Type a company name and watch **9 specialized agents** run a full equity research pipeline. Six agents fan out in parallel — web research, live financials (Yahoo Finance), news sentiment, competitor mapping, SEC filings, macro context — then converge into an analyst agent scoring the company across 5 dimensions. A **self-reflection loop** re-runs any node with low confidence, before a **3-persona debate** (risk-averse / growth-oriented / neutral) produces a final `INVEST` or `PASS` verdict — streamed live to the frontend over SSE and checkpointed to Postgres.

**📉 Cut aggregator inference time from ~4 min → ~60s** by compressing raw graph state into a capped summary and replacing the reflection LLM call with pure code logic.

<div align="center">

`LangGraph.js` `LangChain` `Node.js` `Express` `TypeScript` `React` `Groq (Llama 3.3 70B)` `PostgreSQL` `Prisma` `Docker` `AWS EC2`

</div>
